# 🧹 Bookmark Cleaner

Tiện ích mở rộng Chrome/Edge dọn dẹp bookmark: quét link chết, gỡ trùng lặp,
tự sắp xếp vào thư mục theo chủ đề.

> Đây là bản **minified** để nộp Chrome Web Store. Source code đầy đủ nằm ở repo
> private (liên hệ tác giả).

## Cài đặt thử (developer mode)

1. Tải toàn bộ thư mục này về máy.
2. Mở `chrome://extensions`, bật **Developer mode**.
3. **Load unpacked** → chọn thư mục này.

## Quyền riêng tư

Xem [privacy.html](privacy.html) — tóm tắt: không thu thập dữ liệu, mọi thứ chỉ lưu
trên trình duyệt của bạn (`chrome.storage`), mạng duy nhất là request kiểm tra link
khi bạn bấm "Quét".
